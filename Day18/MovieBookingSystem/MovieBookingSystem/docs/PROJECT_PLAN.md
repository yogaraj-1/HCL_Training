
# Movie Booking System

## Project Overview
A C# console application for managing customers,
movies, and ticket bookings using ADO.NET and SQL Server.

## Technology Stack
- C#
- .NET 10
- ADO.NET
- Microsoft.Data.SqlClient
- SQL Server Express
- Git and GitHub

## Development Workflow
1. Implement a feature.
2. Build and test it.
3. Review the changes.
4. Commit the changes.
5. Document the commit.
6. Push the changes to GitHub.

## Planned Modules
1. Project setup and database connectivity
2. Customer management
3. Movie management
4. Ticket booking and transactions
5. Integration and final testing
