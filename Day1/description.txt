On the first day, we learned the basics of website development, including the structure and functionality of websites. We were introduced to HTML (HyperText Markup Language) for creating webpage structures and CSS (Cascading Style Sheets) for styling and designing web pages.

Later, we applied our learning by developing a personal portfolio website using HTML and CSS. This hands-on activity helped us understand webpage layouts, text formatting, colors, images, and basic styling techniques. Overall, the session provided a strong foundation in web development and practical experience in building a simple, attractive website.
